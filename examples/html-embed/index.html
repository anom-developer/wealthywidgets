🧩 WealthyWidgets — Live Web Components

Demonstrating how anyone can use WealthyWidgets in pure HTML without build tools. Real-time Live API connected!

1. <wealthy-finance>

<wealthy-finance asset="BTC" currency="USD"></wealthy-finance>

2. <wealthy-weather>

<wealthy-weather city="Tokyo" temp="22" cond="Partly Cloudy" unit="C"></wealthy-weather>

3. <wealthy-activity>

<wealthy-activity title="Team Feed"></wealthy-activity>

4. <wealthy-code>

import { WealthyWidgets } from 'wealthywidgets'; // Mount widgets anywhere with one line of code! WealthyWidgets.renderFinance('#crypto-card', { asset: 'ETH', currency: 'EUR' }); 
<wealthy-code title="quickstart.ts">...code here...</wealthy-code>

5. <wealthy-ticker> — Ticker Bar (Бегущая строка)

<wealthy-ticker symbols="BTC,ETH,SOL,BNB,DOGE,XRP,AAPL,NVDA" currency="USD" speed="25"></wealthy-ticker>
