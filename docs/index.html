Overview & Quick Start

Import components and styles into your project. Zero telemetry, fully typed, ready for production.

Setup
# 1. Clone repository git clone https://github.com/anom-developer/wealthywidgets.git cd wealthywidgets # 2. Install dependencies & build pnpm install pnpm run build # 3. Import styles & components in your React root import 'wealthywidgets/dist/styles.css'; import { Button, Card, ActivityWidget, FinanceWidget } from 'wealthywidgets';
